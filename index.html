breakitdown

A/B tests on Spark, sliced by any user or metric segment. Count, binary, ratio and quantile metrics with delta-method intervals, computed on the tables you already have.

GitHub ↗ PyPI ↗ 
from breakitdown import Count, Experiment, MetricTable

exp = Experiment("control", ["t1"],
                 "2024-03-01", "2024-03-14",
                 user_segments=["os", "country"])
events = MetricTable("db.app_events", [Count("clicks")])
exp.analyze(events).by_user_segment("os")
